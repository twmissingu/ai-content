# VISION.md — 稿定 (Gaoding) 项目愿景

> 最后更新: 2026-06-05 | 状态: 从 README / PRD / 代码推断，待创始人确认

## 一句话愿景

**让内容创作者每天只花 10 分钟做决策，其余全部自动化。**

## 问题陈述

内容创作者 80% 的时间花在重复劳动上：搜热点、写初稿、适配多平台格式、逐个平台分发。这些工作耗时但不需要创造力，是自动化的理想对象。

## 解决方案

「稿定」是一个 AI 内容生产系统，自动化从选题到分发的完整流程：

```
信源扫描 → LLM 选题评分 → 人工确认 → 7 阶段写作管线 → 3 平台并行生成 → 人工审批 → 自动分发到草稿箱
```

## 核心设计原则

| 原则 | 说明 |
|------|------|
| **Human-in-the-loop** | 永远不自动发布。选题和审批两个节点必须人工确认 |
| **Domain-agnostic** | 不绑定特定领域，通过配置适配不同内容类型 |
| **Zero external broker** | Agent 间通信使用 JSON 文件系统，不依赖 Redis/RabbitMQ |
| **Cost-conscious** | 每篇文章 $0.12-0.20，月成本 $7-25，预算可控 |
| **Incremental automation** | 从手动触发到定时调度，渐进式自动化 |

## 目标用户

- 独立内容创作者（个人博主、自媒体人）
- 小型内容团队（运营人员）
- 需要多平台分发但不想手动适配格式的创作者

## 关键差异化

1. **3 平台并行生成** — 不是简单复制，而是为微信（长文）、小红书（图文）、抖音（视频脚本）分别生成独立版本
2. **7 阶段质量管线** — 审校、批评修订、标题优化，不是一次 LLM 调用就完事
3. **只到草稿箱** — 其他工具可能自动发布，稿定永远只推到草稿箱，最终决定权在人
