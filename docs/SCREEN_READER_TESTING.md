# 屏幕阅读器测试清单 — 稿定 Dashboard

> 用于 NVDA (Windows) / VoiceOver (macOS) 手动测试

## 测试环境

| 工具 | 平台 | 说明 |
|------|------|------|
| NVDA 2024.4 | Windows | 免费，推荐 |
| VoiceOver | macOS | 系统自带 |
| ChromeVox | Chrome | 浏览器扩展 |

## 测试场景

### 1. 页面导航

- [ ] Skip-to-content 链接：按 Tab 进入页面，第一个焦点应为"跳转到主要内容"
- [ ] 按 Enter 跳转到 `#main-content`
- [ ] Tab 键遍历所有交互元素（按钮、链接、表单）
- [ ] Shift+Tab 反向遍历

### 2. 管线状态视图 (PipelineView)

- [ ] 管线状态卡片被正确朗读（如"管线状态：运行中"）
- [ ] 时间线进度变化时 aria-live 播报
- [ ] 操作按钮有 aria-label（如"查看详情"、"重新运行"）

### 3. 审批队列 (ApprovalView)

- [ ] 待审批数量被朗读（aria-live="polite"）
- [ ] 文章预览内容可访问
- [ ] 审批/驳回按钮有清晰的 aria-label
- [ ] 版本切换时内容变化被播报

### 4. 选题管理 (TopicsView)

- [ ] 选题列表可遍历
- [ ] 选题评分被朗读
- [ ] 操作按钮（确认/跳过）有 aria-label

### 5. 数据分析 (DataView)

- [ ] Chart.js 图表有 aria-label 描述
- [ ] 数据表格可通过键盘导航
- [ ] 筛选控件有 aria-label

### 6. 知识库 (KbView)

- [ ] 搜索框有 aria-label
- [ ] 搜索结果列表可遍历
- [ ] 目录树可通过键盘导航

### 7. 配置管理 (ConfigView)

- [ ] 配置项标签清晰
- [ ] 表单控件有关联的 label
- [ ] 保存/取消按钮有 aria-label
- [ ] 模态框打开时焦点被陷阱

### 8. Toast 通知

- [ ] 通知出现时被 aria-live 播报
- [ ] 关闭按钮有 aria-label="关闭通知"
- [ ] 多条通知不会互相覆盖

### 9. 暗色模式

- [ ] 切换暗色模式后对比度仍满足 WCAG AA (4.5:1)
- [ ] 焦点指示器在暗色模式下可见

### 10. 键盘快捷键

- [ ] `?` 打开快捷键帮助
- [ ] `1-7` 切换视图
- [ ] `Esc` 关闭模态框
- [ ] 快捷键帮助对话框可键盘操作
